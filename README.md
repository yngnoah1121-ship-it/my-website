# DUEL FORGE

デュエル・マスターズの非公式ファンツールです。

- カード価格比較（ドラゴンスター・PAO の価格を自動取得）
- デッキ作成・myデッキ・デッキ画像・デッキコード共有
- テストプレイ（一人回し）

ファイル構成：`index.html`（サイト本体）、`data.json`（カードと価格のデータ）、`sprites/`（カード画像）。
